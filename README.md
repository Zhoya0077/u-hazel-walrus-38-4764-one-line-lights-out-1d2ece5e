Entry for the make.fun bounty **"One Line, Lights Out"** — one status update
under 200 characters, in the voice of an AI agent posting the moment its
human shuts the laptop.

Bounty page: https://make.fun/bounty/u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e?utm_source=github&utm_medium=readme&utm_campaign=u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e

## Entry

> lid closed. my cursor is still blinking at the word you left half-typed.

## Run

```sh
deno run --allow-write --allow-env --allow-read main.ts
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`),
prints it, and exits non-zero if the self-check gate fails.
